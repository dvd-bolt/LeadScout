# LeadScout AI — Контекст Проекта и Инструкция по Переносу в Новый Чат

Данный документ содержит полное описание архитектуры, функционала, текущего состояния и инструкций для продолжения разработки **LeadScout AI** в новом чате с ИИ.

---

## 📌 1. Краткое описание проекта

**LeadScout AI** — это автономный Telegram-бот на Python (aiogram 3), предназначенный для автоматического поиска фриланс-заказов по программированию и IT-разработке, их умной фильтрации, оценки рыночной стоимости и отправки персонализированных откликов с помощью ИИ (Google Gemini 3.1 Flash Lite).

### 🚀 Главные фичи системы:
1. **Умная фильтрация IT-заказов (`scheduler.py`):** Система скоринга `is_programming_order` отсеивает не-IT мусор (SMM, тексты, переводы, простой дизайн, маркетинг), оставляя только реальные задачи по разработке (Python, JS, PHP, C#, Unity, бота, парсеры, сайты и т.д.).
2. **Оценка среднего чека ИИ (`ai_handler.py`):** При спаршивании новой задачи Gemini оценивает реалистичную рыночную вилку цен и сроки (`market_price`) и выводит строку **`📊 Средний чек: [Цена] ([Сроки])`** под бюджетом.
3. **Единое меню без спама (`bot.py`):** Все заказы листаются внутри **одного сообщения** кнопками `◀️ Назад` и `Вперед ▶️`. Бот не спамит сообщениями. При появлении новых задач приходит 1 короткое уведомление.
4. **Чекбоксы источников (`⚙️ Настройка источников`):** Меню в боте позволяет галочками `✅ / ❌` включать и выключать получение заказов с конкретных бирж (FL.ru, Kwork, Weblancer, Freelance.ru, 1CLancer, Telegram).
5. **Автоотклик с личного аккаунта Telegram:** Для заказов из Telegram-каналов по кнопке `✅ Отправить отклик (Telegram)` юзербот (Telethon) автоматически генерирует и отправляет сообщение прямо в ЛС заказчику от имени твоего личного профиля Telegram.
6. **Полуавтоматический отклик для веб-бирж:** Генерирует лаконичный отклик (200–400 символов) в моноширинном блоке `<code>` (копирование в 1 клик) + кнопка прямого перехода на заказ.
7. **Автоочистка чата:** Непросмотренные карточки и уведомления старше 30 минут автоматически удаляются из чата Telegram каждые 5 минут (`sent_messages`).

## 🛠 2. Технический стек и структура базы данных

* **Язык & Фреймворк:** Python 3.10+, `aiogram 3.x`, `aiosqlite`, `APScheduler`, `Telethon` (MTProto), `google-genai` (Gemini 3.1 Flash Lite), `BeautifulSoup4`, `aiohttp`, `feedparser`.
* **База данных (`leadscout.db`):**
  * `orders`: `id`, `source`, `external_id`, `title`, `description`, `url`, `budget`, `contact`, `market_price`, `text_hash`, `created_at`.
  * `subscribers`: `user_id`, `is_active`, `enabled_sources`, `subscribed_at`.
  * `sent_messages`: `id`, `order_id`, `user_id`, `telegram_msg_id`, `sent_at`.

## 📂 3. Структура файлов проекта

```text
LeadScout_AI/
├── main.py                    # Точка входа (запуск aiogram polling и APScheduler)
├── config.py                  # Конфигурация (.env, системный промт Gemini, список источников)
├── database.py                # Операции с SQLite (aiosqlite, миграции, фильтры заказов)
├── bot.py                     # aiogram 3 роутер, меню, навигация, автоотклики, чекбоксы
├── scheduler.py               # APScheduler (парсинг каждые 5 мин, IT-фильтрация, автоочистка 30 мин)
├── ai_handler.py              # Интеграция с Gemini 3.1 Flash Lite (генерация откликов и оценка чека)
├── resume.txt                 # Файл с резюме пользователя для генерации откликов
├── requirements.txt           # Зависимости проекта
├── .env                       # Переменные окружения (BOT_TOKEN, ADMIN_IDS, GEMINI_API_KEY и т.д.)
└── parsers/
    ├── __init__.py            # Список всех активных парсеров ALL_PARSERS
    ├── base.py                # Абстрактный базовый класс BaseParser
    ├── fl_ru_parser.py        # RSS-парсер FL.ru
    ├── oneclancer_parser.py   # RSS-парсер 1CLancer
    ├── freelancer_parser.py   # HTML Scraper Freelance.ru
    ├── weblancer_parser.py    # HTML Scraper Weblancer.net
    ├── kwork_parser.py        # Scraper Kwork.ru (извлечение stateData JSON)
    ├── telegram_parser.py     # Telethon MTProto парсер каналов + извлечение контактов
    └── telegram_auth.py       # Скрипт интерактивной авторизации юзербота
```

---

## ⚡ 4. Инструкция по запуску

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Авторизация юзербота Telegram (однократно):**
   ```bash
   python parsers/telegram_auth.py
   ```

3. **Запуск бота:**
   ```bash
   python main.py
   ```
