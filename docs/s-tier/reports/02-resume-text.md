# Модуль 02 — текст резюме

Status: VERIFIED_LOCAL. Живой проблемный документ не предоставлен.

## Подтверждённые причины

- hh.ru брал широкий `textContent` первого DOM-узла: туда могли попасть скрытые
  служебные узлы, script/style и навигация, а соседние блоки терялись.
- React-превью выводило текст в обычном `<p>`, поэтому браузер схлопывал переносы.
- PDF с повреждённой Unicode-картой шрифта мог пройти прежнюю проверку длины.

## Исправление

- hh.ru читает видимые упорядоченные блоки `innerText`, удаляя служебный DOM.
  Сущности остаются декодированным текстом; преобразования кодировки нет.
- Страницы входа/CAPTCHA прекращают синхронизацию до записи. Пустой текст не
  заменяет существующий снимок; `attach_resume_text` также не пишет пустую строку.
- PDF сохраняет текстовый слой как есть и отклоняет replacement/control/private-use
  glyphs с понятной ошибкой. OCR и генерация текста ИИ не применяются.
- API отдаёт SQLite TEXT без преобразований; React использует `pre-wrap`.
  Аудит получает ровно тот же текст и сохраняет свой immutable source snapshot.

## Регрессии и проверки

- PDF: русский, English, `&`, `<...>`, списки/строки; нечитаемый слой; ошибка импорта.
- Patchright fixture: чистый DOM и порядок блоков; CAPTCHA сохраняет прежний текст.
- SQLite → API → ИИ → audit source: строка совпадает побайтно по содержанию.
- `pytest tests/test_pdf.py` — 8 passed.
- `pytest tests/test_tasks_and_browser.py -k resume_sync` — 4 passed.
- `pytest tests/test_audit_regressions.py -k resume_text_round_trips` — 1 passed.
- Профильный Ruff и `compileall` — успешно.

## Граница проверки

Оригинальный PDF и live hh.ru недоступны, поэтому конкретную неверную font-map
не воспроизводили. Старые снимки и аудиты не менялись. Для восстановления старого
повреждённого текста повторите синхронизацию с hh.ru либо импорт исходного PDF.

## Финальная перепроверка

- DOM-клон подключается только на время чтения innerText, поэтому учитываются
  реальные CSS-видимость и переносы.
- Узлы hidden и aria-hidden не попадают в текст резюме.
- Frontend production build и полный pytest выполнены успешно: 276 passed.
