Повторная проверка после выпуска: [исправления и 227 прошедших тестов](ADMIN_RECHECK_2026-09-11.md).

## Результат

- `1022352992` — ROOT, ACTIVE: управление участниками, ролями, доступом и всей работой.
- `8941766376` — ADMIN, ACTIVE: диагностика и остановка всех, кроме ROOT.
- Вход: **Mini App → Настройки → Администрирование**. Четыре вкладки Mono: обзор, люди (ROOT), задания, журнал.
- Личные кабинеты сохраняют изоляцию. Административные ответы содержат технические метаданные,
  а не резюме, письма, ответы анкет, cookies, прокси, CAPTCHA/OTP и результаты генераций.

Миграция SQLite v6 → v7 создаёт отдельные таблицы доступа, заданий, команд и ошибок. Bootstrap
однократный; последующие перезапуски не возвращают отозванные роли из старого списка владельцев.
ROOT защищён сервером. Cookie теперь содержит версию допуска; роль и статус читаются из базы.

Отключение транзакционно закрывает доступ, отзывает сессии, выключает автопоиск и сохраняет команду.
Дальнейшая остановка имеет отдельные результаты и переживает перезапуск. Неудачные закрытия можно
повторить; восстановление до завершения остановки запрещено. Адресная отмена сохраняет независимые
задания и общие браузерные/AI-ресурсы. Прерванная анкета не отправляется повторно автоматически.

Новые проверки покрывают:

- реальные начальные ID и однократность bootstrap, несовпадение ROOT, ограничения схемы;
- добавление до первого входа, роли, блокировку/восстановление, отзыв старых cookie и понижение ADMIN;
- запрет назначения/изменения ROOT, отсутствие доверия к роли в cookie, CSRF, Origin и личную изоляцию;
- положительный 64-битный ID строкой, ошибочные значения, пагинацию больше 100 участников;
- адресную и массовую остановку, защиту ROOT, выключение автоматизации и новый ручной запуск;
- гонки регистрации/блокировки и смены роли/остановки, объединение одновременных отмен одного задания;
- отмену операции импорта и ожидания браузера, сохранение незавершённого аккаунта входа;
- таймаут без ложного успеха, повтор закрытия ресурсов и восстановление долговечной команды;
- сохранность пользовательской истории при очистке технических данных;
- полный путь **React → API → сервисы → настоящий координатор → SQLite**, включая отмену отправки анкеты;
- закрытие уже открытой админки после отзыва роли, очистку кабинета после отключения;
- конфликт revision без повторной мутации, отсутствие автоматической повторной отправки;
- ширины 320, 390, 430, 760 и 1280 px, полное отображение длинного ID, отсутствие горизонтальной прокрутки;
- получение ссылки на бота и понятный ответ при недоступности Clipboard API.

Внешние действия hh.ru в этих сценариях подменены. Проверки не выполняли реальные отклики,
не отправляли приглашения и не меняли чужие резюме.

## Проверка работающего приложения

Текущий адрес: https://personalized-bind-prefix-mentor.trycloudflare.com

Backend и frontend обновлены. В локальном сервере и через HTTPS проверены:

| Запрос | ROOT | ADMIN |
|---|---:|---:|
| `/healthz` | 200 | 200 |
| `/api/v1/me` | 200, ROOT | 200, ADMIN |
| `/api/v1/admin/overview` | 200 | 200 |
| `/api/v1/admin/members` | 200 | 403 |

Ответ обзора подтвердил успешное чтение базы, живую задачу polling и запущенный scheduler.
Живая проверка Chromium подтвердила наличие вкладки «Люди» у ROOT и её отсутствие у ADMIN;
у ROOT доступно управление вторым участником, главная роль защищена. Ошибок JavaScript/консоли
в этом проходе не обнаружено. HTML, JavaScript и CSS, полученные через HTTPS, совпадают с финальной
локальной production-сборкой по содержимому.

Для безопасной проверки ролей использовались короткие технические сессии. Они не имитируют факт
личного входа владельцев: имя и `last_login_at` в рабочей базе этим проходом не менялись.
**Открытие Mini App внутри Telegram на телефонах владельцев требуется проверить отдельно.**
После изменения формата cookie Mini App следует закрыть и открыть заново.
Платная генерация ИИ и реальные операции hh.ru в приёмочный проход не входят.
