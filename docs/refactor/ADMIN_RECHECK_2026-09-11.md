# Повторная проверка админки LeadScout

11 сентября 2026 года. Исправления установлены в работающий backend и frontend.

## Что проверено и исправлено

Проверка проведена заново: чтение кода, воспроизведения на временных SQLite-базах,
настоящий Chromium → production React → API → сервисы/координатор → SQLite.
Рабочие участники и их данные в тестах не изменялись; внешние действия hh.ru подменены.

| Сценарий | Найденная проблема и исправление |
|---|---|
| Отмена закрытия ресурса или cleanup callback | `CancelledError` внутри `gather` ошибочно считался успехом. Теперь результат — ошибка, ресурс остаётся в реестре для повторной остановки; технический статус — STOPPING. |
| Отмена закрытия ресурсов пользователя | Управляющая команда оставалась PENDING после завершения её корутины. Теперь показывается NEEDS_CLEANUP, повтор cleanup завершается отдельно, доступ остаётся закрытым. |
| Новый шаг входа при административной остановке | Во время закрытия входа можно было начать новый вход или передать OTP. Теперь до окончания остановки возвращается 409; независимый аудит продолжает работать. |
| Обновление журнала после завершения из другого окна | Карточка сохраняла старый NEEDS_CLEANUP, хотя обновлённый список содержал SUCCEEDED. Теперь принятый конечный результат заменяет устаревшее состояние карточки. |
| Завершение задания во время ожидания остановки | Дополнительно проверена гонка на границе блокировки: повторное чтение сохраняет SUCCEEDED уже завершившейся работы, не заменяя его на INTERRUPTED. |

Каждый случай сначала воспроизведён отдельным падающим тестом. Добавлено семь проверок
с учётом параметризации. Прежние проверки не ослаблялись.

## Работающая версия

Адрес: https://personalized-bind-prefix-mentor.trycloudflare.com

Через localhost и HTTPS выполнены 24 проверки API для ROOT/ADMIN: кабинет, обзор,
люди, задания, действия и ошибки. ROOT получает список людей, ADMIN получает 403.
Запрос без сессии и запрос с устаревшей версией допуска получают 401.

Проверены целостность SQLite v7, активные роли обоих владельцев, выполнение polling и
запущенный scheduler. HTML/JS/CSS через HTTPS совпадают с установленной сборкой по содержимому.
Перед обновлением незавершённых заданий не было. Бот и Mini App перезапущены.

В Chromium через localhost подтверждены правильные вкладки обеих ролей, список участников
у ROOT и отсутствие JavaScript-ошибок. Сохранены новые снимки:

- [Обзор ROOT](../../output/admin-verification/recheck-local-root.png)
- [Обзор ADMIN](../../output/admin-verification/recheck-local-admin.png)
- [Люди у ROOT](../../output/admin-verification/recheck-local-people.png)

Автоматический Chromium при прямом открытии внешнего HTTPS-адреса получил
`net::ERR_CONNECTION_CLOSED` для обеих ролей. HTTP-клиент с обычной проверкой TLS успешно
получил API и файлы по тому же адресу. Поэтому внешний браузерный проход не отмечается
как пройденный; интерфейс проверен через localhost, публичный адрес — отдельными HTTPS-запросами.
Открытие Mini App внутри Telegram на телефонах владельцев остаётся отдельной проверкой.
Реальные отклики hh.ru, платная генерация ИИ и рассылка сообщений в этот проход не выполнялись.
