# Реализация Mono — 11 сентября 2026

## Результат

Все четыре раздела переведены на монохромный дизайн: белый фон, чёрные контуры,
контрастные действия, крупные заголовки, SVG-иконки и локальный Inter Variable
с кириллицей и SIL Open Font License. Приложение сохраняет светлый вид при обеих темах Telegram.

Главная повторяет порядок блоков выбранного макета. Данные берутся из активного аккаунта:
дневной прогресс, число анкет, резюме, статус, время МСК и события. Незапланированный
запуск обозначен словами; первый вход не содержит демонстрационной статистики.
Массовые действия находятся в раскрываемом блоке «Все аккаунты».

Сохранены существующие формы и сценарии входа, CAPTCHA, импорта, аудита, сравнения,
анкет, удаления с подтверждением, CSRF и доступа двух владельцев. Новый параметр
`tab` открывает проверку или историю; прямая ссылка на анкету имеет приоритет.

## Изменения данных и найденные проблемы

- Новый `active_pending_review_count` использует COUNT с фильтрами владельца,
  аккаунта и статуса, независимо от ограничения списка в 100 анкет.
- Исправлена передача общего scheduler при получении времени для dashboard:
  ранее поле главной могло быть пустым при заполненном времени в списке аккаунтов.
  Ошибка сначала воспроизведена тестом `test_dashboard_uses_context_schedule`.
- Устранено переполнение карточки незапланированного запуска на узком экране.
- Запуск и остановка блокируют повторное действие до обновления dashboard;
  смена аккаунта очищает прежние сообщения и массовые результаты.
- Индикатор прогресса состоит из сегментов без CSS-градиентов; неверный лимит
  отображается как «—», превышение ограничивает заполнение до 100%.

Автоматические браузерные проверки используют собранный React. Часть сценариев проходит
через настоящий FastAPI и временную SQLite, а сквозные тесты отправки — через настоящий
сервис, координатор и задания с подменой внешнего hh.ru.

Проверены:

- Все четыре раздела при ширинах 320, 390, 430, 760 и 1280 px, отсутствие горизонтальной
  прокрутки; мобильные и desktop-скриншоты сохранены.
- Белая палитра и вызовы цветов SDK при переключении Telegram dark → light.
- Увеличение основного текста до 125%, длинные названия, нижний safe-area,
  уменьшение высоты окна до 350 px и доступность кнопки сохранения.
- Прогресс 0%, 48%, 100%, превышение, 200/200, нулевой, отсутствующий и null-лимит.
- Точный COUNT для 107 ожидающих анкет, второй аккаунт, ноль, отсутствие аккаунта,
  изоляция двух владельцев.
- Одиночный запуск и остановка, массовые действия и отдельные результаты, смена аккаунта,
  CAPTCHA и её ошибка, импорт с дозаполнением, аудит и сравнение.
- Сохранение и повторное открытие черновика, прямые ссылки, длительная отправка,
  успех, ошибка, остановка, потерянный ответ, конфликт revision, восстановление без автоповтора.

Сборка Vite/TypeScript, Ruff, форматирование Python, pip check, npm ls, compileall
и git diff --check проходят. Проверка ссылок CSS Modules не обнаружила отсутствующих классов.
Форматирование старых Markdown-планов в объём изменения не входит.

## Работающая версия и откат

Предыдущие исходники и frontend-бандл сохранены до изменений:
`scratch/checkpoints/before-mono-20260911-161237/web/{src,dist}`.
Для отката frontend нужно сохранить текущий `web/dist`, затем восстановить содержимое
старого `dist` из этой копии. Backend совместим со старым frontend; миграций схемы нет.

Общий runtime перезапущен после успешных проверок. Сервер PID 28437; прежний
Cloudflare Quick Tunnel сохранён. Адрес: https://personalized-bind-prefix-mentor.trycloudflare.com.

- `/healthz` по localhost и публичному HTTPS: 200.
- HTML отдаёт итоговый `index-CMiqtrPt.js`, CSS и локальный шрифт доступны с HTTP 200.
- `/api/v1/me` по обоим адресам проверен с локально подписанными сессиями обоих
  разрешённых владельцев: правильный `user_id`, `active_pending_review_count = 0`.
- В рабочей базе нет подключённых hh.ru-аккаунтов и активных отправок; проверен
  экран первого запуска без статистики. Дополнительный SQLite backup перед перезапуском:
  `scratch/checkpoints/before-mono-20260911-161237/leadscout-before-restart.db`, integrity_check = ok.
- agent-browser по localhost: кабинет, переход в настройки, белый фон, light color-scheme,
  отсутствие горизонтального переполнения и JS-ошибок. В журнале нового server process
  не обнаружено ошибок/предупреждений на момент завершения проверки.

Прямое открытие внешнего HTTPS через автоматический Chromium снова завершается
`ERR_CONNECTION_CLOSED`; публичная статика/API проверены urllib с обычной проверкой TLS.
Ранее то же ограничение наблюдалось и на контрольном внешнем сайте. Эта проверка не
подтверждает открытие в Telegram на телефонах.

## Границы проверки

Автоматические проверки не заменяют открытие Mini App внутри Telegram на устройствах
обоих владельцев. Экранная клавиатура и safe-area проверены моделированием размеров
браузера и CSS-переменных, не на физических iPhone/Android. Реальные отклики, импорт
в рабочий hh.ru и отправка сообщений владельцам при проверке дизайна не выполнялись.

[Inter — официальный источник](https://rsms.me/inter/).
[Telegram Mini Apps — методы цветов и safe-area](https://core.telegram.org/bots/webapps).
