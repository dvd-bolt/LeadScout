# Рефакторинг LeadScout

Текущая архитектура и границы зависимостей описаны в [ARCHITECTURE.md](ARCHITECTURE.md).
Последняя повторная проверка: [SECOND_REVIEW_2026-09-11.md](SECOND_REVIEW_2026-09-11.md) —
174 теста прошли без ошибок и пропусков.
Исправления после независимой проверки и фактически выполненные проверки — в
[FINAL_VERIFICATION_2026-09-11.md](FINAL_VERIFICATION_2026-09-11.md).

Mini App — основной интерфейс. Бот — вход, уведомления и остановка. Пять бизнес-сервисов
разделены; API, бот и scheduler получают единый `AppContext`. Схема SQLite — v6.
Внедрены единая нормализация логинов, версионирование черновиков и корректное отображение
результатов фоновой отправки. Ошибка ИИ больше не маскируется успешной нулевой оценкой.
