## Повторный запуск после остановки

1. Убедитесь, что старый экземпляр `server_app.py` и прежний туннель остановлены, порт 8000 свободен.
2. В отдельном терминале из корня проекта запустите:

   ```bash
   cloudflared tunnel --url http://127.0.0.1:8000 --protocol http2 --no-autoupdate
   ```

3. Скопируйте выданный HTTPS URL в `.env`: `APP_URL` и `WEB_APP_ORIGINS`; hostname без схемы — в `DOMAIN`. Сохраните токены, список владельцев и существующий `SESSION_ENCRYPTION_KEY`.
4. В другом терминале запустите `.venv/bin/python server_app.py`.
5. После успешного ответа публичного `/healthz` выполните `.venv/bin/python -m scripts.set_mini_app_menu`. Скрипт обновит меню без отправки сообщений и проверит сохранённый URL.
6. Заново откройте Mini App в Telegram. При foreground-запуске Ctrl+C в обоих терминалах останавливает приложение и туннель.

Quick Tunnel выдаёт временный адрес, который меняется при новом запуске; гарантии доступности нет. Для постоянной ссылки нужен постоянный туннель с доменом либо размещение на сервере. [Документация Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/).
