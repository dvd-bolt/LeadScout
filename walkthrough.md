# Проверка запуска LeadScout

Проверено 14 сентября 2026 года после чистого перезапуска единого лаунчера.

## Результат

- Mini App, API, планировщик и Telegram polling запущены одним экземпляром.
- Cloudflare Quick Tunnel создан, а кнопка меню бота подтверждена для двух владельцев.
- Локальный `GET /healthz` отвечает `200 {"status":"ok"}`.
- В журнале сервера есть успешный внешний запрос через туннель: `GET /healthz` — `200`.
- Production-сборка интерфейса проходит: `npm --prefix web run build`.
- Полный набор тестов проходит: `276 passed`.

## Ограничение среды проверки

Встроенный браузер и PowerShell этого компьютера блокируют TLS-запросы к `trycloudflare.com`
на уровне локального прокси/расширения (`ERR_BLOCKED_BY_CLIENT` / TLS handshake error). Это не
ошибка приложения: сервер за туннелем подтвердил внешний `200` в собственном журнале.

## Что оставлено работающим

Сеанс лаунчера продолжает работать в текущей среде. Quick Tunnel временный: после его остановки
потребуется новый адрес и повторное обновление кнопки Mini App.
