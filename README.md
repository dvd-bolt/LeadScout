# 🚀 LeadScout AI — Автономный ИИ-ассистент поиска работы на hh.ru

**LeadScout AI** — это высокопроизводительная мультиаккаунтная система на базе **Google Gemini 3.5 Flash Lite** и **Patchright Stealth (Playwright)** для полной автоматизации процесса поиска работы, отклика на вакансии с уникальными сопроводительными письмами и проведения глубокого ATS-аудита IT-резюме.

---

## 📌 Основные возможности

1. **🤖 Умный автоотклик на hh.ru (Auto-Apply Engine):**
   - Автоматический поиск вакансий по должностям, вилкам зарплат и ключевым навыкам.
   - Генерация персонализированных сопроводительных писем под требования каждой вакансии с помощью LLM Gemini.
   - Фильтрация повторных вакансий, дублей и неподходящих работодателей.
   - Поддержка суточных лимитов и умных задержек для защиты аккаунтов от блокировок.

2. **📄 Мульти-способы работы с резюме:**
   - **Прямая выгрузка PDF:** загрузка готового файла резюме на hh.ru в один клик.
   - **Пошаговый ИИ-мастер заполнения:** если прямой импорт недоступен, Gemini извлекает структурированный JSON из текста/PDF и пошагово через инпуты заполняет профессиональную роль, опыт работы, образование и навыки.
   - **Локальное кэширование (0.01s):** хранение списков резюме в SQLite `resumes_json` для моментального отклика клавиатур бота в Telegram.

3. **📊 ИИ-Аудит и ATS-Скоринг резюме (Google XYZ Standard):**
   - Оценка резюме по 5 ключевым категориям: *Полнота данных, Форматирование, Релевантность опыта, Навыки, Ключевые слова*.
   - Детекция скрытых ATS-барьеров и генерация конкретных рекомендаций по методологии Google XYZ (Accomplished [X] as measured by [Y], by doing [Z]).
   - Генерация профессионального аналитического PDF-отчета.

4. **👥 Мультиаккаунтность и бессбойная авторизация:**
   - Сохранение шифрованных сессий `storage_state` и прокси для каждого аккаунта.
   - Поддержка ввода SMS-кодов и автоматического распознавания капчи на hh.ru.

## ⚙️ Принципы работы системных компонентов

### 1. Patchright Stealth & Эмуляция человека (`utils/humanization.py`)
Бот не использует стандартные бот-запросы HTTP POST, так как hh.ru заблокирует их через Cloudflare / Qrator. Вместо этого используется **Patchright Stealth**:
- Управление реальным Chrome браузером с маскировкой под обычного пользователя.
- Имитация естественных движения курсора (`human_click`) и переменной скорости печати текста с опечатками и паузами (`human_type`).

### 2. Кэширование резюме и мгновенный отклик
Для устранения задержек Telegram-бота список резюме аккаунта сохранен в колонке `resumes_json` SQLite базы данных. Бот считывает локальный кэш за **0.01 секунды**. При нажатии кнопки `🔄 Синхронизировать hh.ru` происходит актуализация кэша из браузера.

### 3. Обработка структуры резюме с помощью Gemini 3.5 Flash Lite
Файл `ai_handler.py` через официальный SDK `google-genai` преобразует неструктурированный текст PDF в типизированную Pydantic-схему `StructuredResume`:
- Автоматически вычленяются места работы, должности, даты, компании, навыки и образования.
- Если выгрузка PDF на hh.ru недоступна, структурированные данные пошагово вводятся в интерфейс веб-мастера hh.ru.

## 🚀 Запуск и установка

1. **Клонирование и установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   patchright install chromium
   ```

2. **Настройка файла `.env`:**
   ```env
   BOT_TOKEN=your_telegram_bot_token
   GEMINI_API_KEY=your_google_gemini_api_key
   SECRET_KEY=your_encryption_secret_key
   ```

3. **Запуск бота:**
   ```bash
   python main.py
   ```
