# 🤖 LeadScout AI — Полная спецификация проекта, Стек и Дорожная карта (Roadmap)

В данном документе описана полная архитектура, текущий функционал, стек технологий и будущий план развития автономного Telegram-бота **LeadScout AI**.

---

## 📌 1. Обзор проекта

**LeadScout AI** — это автономная SaaS-платформа в виде Telegram-бота для автоматизации поиска работы и отправки персонализированных откликов на вакансии **hh.ru** с помощью искусственного интеллекта **Google Gemini 3.5 Flash Lite**, анонимного браузерного антидетекта **Patchright Stealth** и асинхронной архитектуры на Python.

---

## 💻 2. Полный стек технологий

### Core Frameworks & Libraries
- **Язык разработки:** Python 3.11+
- **Telegram Bot Framework:** `aiogram 3.x` (Router architecture, FSM, Custom Keyboards)
- **Искусственный Интеллект:** `google-genai` (Модель `gemini-3.5-flash-lite`, Pydantic Structured Outputs `response_schema`)
- **Браузерная Автоматизация & Антибот:** `patchright` (асинхронный Chromium с блокировкой рекламы/метрик/медиа)
- **База Данных:** SQLite + `aiosqlite` (асинхронный слой работы с БД)
- **Очереди & Фоновые Задачи:** `taskiq` + `taskiq-redis` (с автоматическим фоллбэком на `InMemoryBroker`, если Redis не запущен)
- **Планировщик:** `apscheduler` (AsyncIOScheduler)
- **Безопасность & Шифрование:** `cryptography` (Fernet AES-256 с детерминированным SHA-256 ключом)
- **Парсинг Документов:** `pypdf` (извлечение текста из PDF-резюме)
- **Эмуляция человека:** Алгоритм кубических кривых Безье для движений мыши, таймингов и посимвольного ввода (`humanization.py`)

## ⚙️ 3. Текущая работа Telegram-бота (Работает на 100%)

### 🔑 1. Безопасная 2FA-авторизация hh.ru
- Ввод телефона или Email через Telegram FSM.
- Автоматический перехват картинки капчи hh.ru в боте при её появлении с кнопками `🔄 Обновить картинку` и `🌐 English/Русский`.
- Посимвольный ввод СМС-кода в Chrome и сохранение зашифрованной сессии (**Fernet AES-256**).

### 📄 2. Работа с резюме
- Прием **PDF-файла резюме** прямо в чат Telegram, извлечение текста через `pypdf`.
- Автоматическая выгрузка и публикация PDF-файла в профиле `hh.ru`.
- Синхронизация списка резюме пользователя с сайта hh.ru, дедупликация по 32-значному ID, выбор активного резюме `🟢 [АКТИВНО]`.

### 🤖 3. ИИ-Отклик на базе Gemini 3.5 Flash Lite
- Автоматическое извлечение ключевых слов поиска из резюме кандидата.
- Поиск вакансий с фильтрацией по ЗП, только удаленке (`schedule=remote`) и стоп-словам.
- Оценка релевантности вакансии контексту резюме (`is_relevant: true/false`, `relevance_reason`).
- Составление уникальных коротких сопроводительных писем (40–70 слов) в стиле живого специалиста без ИИ-штампов.
- Прохождение вопросов и анкет работодателя. При низкой уверенности ИИ — отправка запроса на подтверждение соискателю в Telegram.

### 📊 4. Интерфейс и контроль
- Главное меню: `🚀 Запустить автоотклик` / `⛔️ Остановить автоотклик`, `📊 Статистика`, `📜 История откликов`, `📄 Мое резюме`, `⚙️ Настройки`, `🔑 Авторизация hh.ru`.
- Настройки: суточный лимит, минимальная ЗП, удаленка, прокси, ключевые слова, стоп-слова.

## 🔮 4. Ближайшая и Будущая Дорожная Карта (Roadmap)

### Phase 1: Мульти-аккаунтность (Текущий этап разработки 🚀)
- **Поддержка N аккаунтов hh.ru на одного пользователя Telegram:**
  - Создание таблицы `hh_accounts` с независимым хранением зашифрованных куки, резюме, ЗП, прокси и ключевых слов.
- **Параллельный запуск 2 браузеров одновременно на 1 IP-адресе:**
  - Настройка `asyncio.Semaphore(2)` в воркере.
  - Добавление случайной стартовой задержки (Staggering delay: 5–15 сек) для разнесения сетевых запросов двух аккаунтов.
- **Бесшовное переключение аккаунтов (`🔄 Сменить аккаунт`):**
  - Возможность выбора активного профиля в Telegram UI без сброса сессий и без удаления куков.
  - Кнопки управления: `🚀 Запустить ВСЕ`, `⛔️ Остановить ВСЕ`, `🗑 Удалить аккаунт`.

### Phase 2: Аналитика и Отклик на сообщения (План 📈)
- Мониторинг приглашений на интервью и просмотров резюме рекрутерами на hh.ru.
- Уведомления в Telegram при получении ответа от работодателя.

### Phase 3: Мульти-платформенность (План 🌐)
- Интеграция модулей автопоиска работы для **SuperJob**, **Хабр Карьера**, **Freelancehunt** и **Kwork**.
