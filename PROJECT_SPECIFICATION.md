# LeadScout AI: текущая спецификация

Актуальная архитектура рассчитана на один Python-процесс локально или в контейнере.

## Runtime

- Aiogram long polling и `MemoryStorage` для незавершенных диалогов.
- APScheduler в часовом поясе `Europe/Moscow`.
- `TaskCoordinator` вместо Redis/Taskiq: одна задача на аккаунт, общий browser semaphore и account lock.
- Patchright bundled Chromium; browser pool разделяется по нормализованному proxy URL.
- Один lifecycle-managed асинхронный Google GenAI client.
- `AppContext` передаёт один граф зависимостей в API, бот и планировщик; координатор,
  браузерный пул и блокировки не создаются повторно.
- API разделён на `app`, `auth`, `dependencies`, `schemas` и группы routes.

## Данные

- SQLite schema v6, WAL, foreign keys на каждом соединении и версионные миграции.
- Пользовательские аккаунты, аудиты, resume snapshots и анкеты читаются только со scoped `user_id`.
- Уникальный отклик определяется парой `(account_id, vacancy_hh_id)`.
- Успешный отклик и дневной счетчик записываются одной транзакцией.
- Анкета проходит состояния `PENDING/FAILED/NEEDS_REVIEW -> SUBMITTING -> SUBMITTED/FAILED`
  атомарно; `SKIPPED` идемпотентен, а отправляемая или отправленная анкета не пропускается.
- Длительная операция проходит `PENDING -> RUNNING -> SUCCEEDED/FAILED/NEEDS_INPUT`.
- Черновик сохраняет неполные ответы, повышая `revision`; подтверждение проверяет полноту
  и атомарно захватывает проверенную версию. Несовпадение `expected_revision` возвращает 409.
- Телефонные ключи нормализуются одинаково при миграции, создании и поиске. Коллизия внутри
  пользователя останавливает миграцию без объединения или удаления аккаунтов.

## Правила Автоматизации

- Автоотклик требует активную hh.ru-сессию, выбранное резюме и непустой текст именно этого резюме.
- Успех подтверждается DOM-состоянием hh.ru; совпадение части URL не считается подтверждением.
- Анкета отправляется автоматически при confidence `>= 0.85`, заполненных обязательных полях и допустимых вариантах.
- Юридические, consent-, citizenship-, relocation- и salary-вопросы всегда требуют подтверждения пользователя.
- Выключенное сопроводительное письмо намеренно заменяется точкой `.`.
- URL для матчинга ограничен HTTPS-доменами `hh.ru` и `*.hh.ru`; Gemini получает извлеченное описание, не URL.
- Сравнение использует зафиксированный исходный текст конкретного аудита. Аудит отдельного
  текста или PDF не требует аккаунта hh.ru.

## Безопасность

- `SESSION_ENCRYPTION_KEY` обязан быть валидным уникальным Fernet-ключом; fallback отсутствует.
- TLS Telegram API использует стандартную проверку сертификатов.
- OTP, captcha и proxy credentials не логируются; proxy credentials маскируются в интерфейсе.
- PDF ограничен по размеру, страницам и тексту и обрабатывается в уникальном временном каталоге.
- Telegram/ReportLab-данные экранируются, callback ID проверяются и привязываются к владельцу.
- Mini App скрывает сессионные данные и proxy credentials; изменения требуют допустимый Origin
  и CSRF-токен из подписанной HttpOnly cookie-сессии.
